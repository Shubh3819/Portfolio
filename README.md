## ⚙️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Shubh3819/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL printed in the terminal.

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## 🌍 Deployment

This portfolio can be deployed on [Vercel](https://vercel.com/):

1. Import the GitHub repository into Vercel.
2. Select **Vite** as the framework if it is not detected automatically.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. Deploy the project.

Future pushes to the connected production branch can trigger automatic deployments.
