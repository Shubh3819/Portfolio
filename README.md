# Subhrangshu Chatterjee — Portfolio

React + Vite + Tailwind CSS + Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Before you publish

All personal details live in **`src/profile.js`**.

1. Set `email`, `github`, `linkedin` and the intro video link (`loom`).
2. Add your photo as **`public/profile.png`** (square or portrait works best; falls back to your initials if missing).
3. Add your resume as **`public/resume.pdf`**.
4. For each project, fill in `github` and `demo`. Empty values hide the link, so nothing broken is shown.

## Deploy

```bash
npm run build   # outputs to dist/
```

Upload `dist/` to Vercel, Netlify or GitHub Pages (or connect the repo and use `npm run build` as the build command with `dist` as the output directory).
